Ocean forcing

The ocean forcing supplies the ambient temperature $T_a$ and salinity $S_a$ that the layer entrains and that set its buoyancy. They are sampled from vertical profiles at the depth of the layer base, $z_b - H$. A model is driven by a CavityForcing, which pairs an ocean forcing with an ice forcing; passing an ocean forcing on its own to Model pairs it with the default PrescribedIceForcing(-25.0).

forcingprofilesuse
OceanForcing1Done, for the whole domainidealised setups and single cavities
PerBasinOceanForcing1Done per basin, with a basin index for every celldomains spanning several basins (e.g. pan-Antarctic)
Laddie.OceanForcing2Done per grid celllaterally varying forcing; not exported, not on the Reactant backend

ISOMIPForcing builds the warm and cold ISOMIP+ profiles as an OceanForcing1D; see the ISOMIP+ example for plots. For ocean models without ice-shelf cavities, front_ocean_forcing builds a PerBasinOceanForcing1D with one profile per ice-front water column, shared by the cavity cells behind it.

The basin map of PerBasinOceanForcing1D and the per-cell profiles of OceanForcing2D cover the full domain including the border ring, like a 2D ice temperature, and Model crops them with the grid. Every cell of the basin map, land and ocean included, must hold a valid basin index.

Vertical lookup

The profiles are stored on a uniform depth grid (1 m for profiles built with OceanForcing1D). At each time step the local plume-base depth $z_b - H$ indexes this grid and linear interpolation supplies the $T_a$, $S_a$ values that enter the density, entrainment and convection terms; depths beyond the profile take its end values.

The 1 m grid is the storage, not the profile's own resolution: OceanForcing1D sorts, resamples and extrapolates flat from whatever samples it is handed. So the levels a profile is built on are part of the forcing — handing it an analytic function every metre and handing it the same function on a model's coarse ocean levels are two different forcings wherever the profile is curved, such as across a thermocline. Reproducing another model means sampling where it samples, not only using its formula.

API

Laddie.AbstractOceanForcing — Type

Supertype of every ocean forcing: the ambient temperature and salinity the meltwater layer entrains and exchanges heat with.

Laddie.OceanForcing1D — Type
struct OceanForcing1D{FT, V<:(AbstractVector)} <: AbstractOceanForcing

Ambient T/S as one vertical profile resampled onto a uniform 1 m z-grid.

Construct it from arbitrary samples with OceanForcing1D(Tz, Sz, z), which sorts by depth, resamples, and extrapolates flat beyond the data range.

Fields

  • Tz::AbstractVector: ambient temperature on the uniform z-grid (°C)

  • Sz::AbstractVector: ambient salinity on the uniform z-grid (psu)

  • z::AbstractVector: depths of the uniform z-grid (m, negative downward)

  • dz::Any: z-grid spacing (m)

  • z0::Any: depth of the first z-grid point (m)

Laddie.PerBasinOceanForcing1D — Type
struct PerBasinOceanForcing1D{FT, M<:(AbstractMatrix), I<:(AbstractMatrix), V<:(AbstractVector)} <: AbstractOceanForcing

Ambient T/S from a handful of vertical profiles, one per basin, and a map assigning every grid cell to a basin. Each cell samples its basin's profile at the depth of its plume base, exactly as an OceanForcing1D would. This is the forcing of a domain that spans several basins (e.g. pan-Antarctic) when each basin is forced by its own front profile: n_basins × nz numbers instead of an OceanForcing2D's nx × ny × nz.

basin covers the full domain including the border ring (like a 2D T_ice_base), and Model crops it with the grid. Every cell must hold a valid basin index in 1:size(Tz, 1), land and ocean included (the ambient kernel runs on every cell). Assign cells outside any basin to the nearest one before building the forcing.

Construct it from per-basin OceanForcing1Ds with PerBasinOceanForcing1D(profiles, basin), which resamples them onto a common grid, or from (n_basins, nz) matrices on uniform levels with PerBasinOceanForcing1D(Tz, Sz, z, basin). A "basin" is any group of cells sharing a profile: front_ocean_forcing builds one with a profile per ice-front water column, which cells of the cavity behind it share.

Supported by the Reactant backend, including differentiation through it.

Fields

  • Tz::AbstractMatrix: ambient temperature per basin and level, (n_basins, nz) (°C)

  • Sz::AbstractMatrix: ambient salinity per basin and level, (n_basins, nz) (psu)

  • basin::AbstractMatrix: basin index of every cell, in 1:n_basins

  • z::AbstractVector: depths of the uniform z-grid (m, negative downward, ascending)

  • dz::Any: z-grid spacing (m)

  • z0::Any: depth of the first z-grid point (m)

Laddie.OceanForcing2D — Type
struct OceanForcing2D{FT, A<:AbstractArray{FT, 3}, V<:AbstractArray{FT, 1}} <: AbstractOceanForcing

Laterally varying ambient T/S: one vertical profile per grid cell, all on the same uniform z-grid. Tz and Sz are (nx, ny, nz) arrays covering the full domain including the border ring (like a 2D T_ice_base); Model crops them with the grid. Each cell samples its own column at the depth of its plume base, and depths outside the grid take the nearest level, as for OceanForcing1D.

Not exported, and not yet supported by the Reactant backend.

Fields

  • Tz::AbstractArray{FT, 3} where FT: ambient temperature per cell and level (°C)

  • Sz::AbstractArray{FT, 3} where FT: ambient salinity per cell and level (psu)

  • z::AbstractVector: depths of the uniform z-grid (m, negative downward, ascending)

  • dz::Any: z-grid spacing (m)

  • z0::Any: depth of the first z-grid point (m)

Laddie.ISOMIPForcing — Function

Ambient T/S profiles for the ISOMIP+ protocol (Asay-Davis et al. 2016), returned as an OceanForcing1D. Profiles are linear from the surface (T = −1.9 °C, S = 33.8 psu) to 720 m depth.

  • isomipcond = :warm: T = +1.0 °C, S = 34.7 psu at depth (strong melting).
  • isomipcond = :cold: T = −1.9 °C, S = 34.55 psu at depth (near-freezing).

Used automatically by build_isomip; pass it as the forcing argument of Model to use it with another geometry.

ISOMIPForcing(:cold; FT = Float32)
