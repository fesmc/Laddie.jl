Mask preprocessing

Masks derived from ice-sheet geometry often contain features the layer cannot use: enclosed ocean pockets, shelf patches with no route to the open ocean, or isolated single cells. Grid(mask, z_draft, dx, dy; preprocess = [...]) runs a list of steps, in order, on a copy of the mask before domain cropping:

stepeffect
FillOceanHolesPreprocessenclosed ocean pockets become land
FillShelfHolesPreprocessshelf patches not connected to the open ocean become grounded ice
FillSmallShelfPatchesPreprocessshelf patches smaller than min_size cells become grounded ice
FillSmallGroundedPatchesPreprocessisolated grounded patches (pinning points, rumples) smaller than min_size cells become shelf
MarkGapsPreprocessopen-ocean cells where a reference footprint has ice become gaps (4)

Each step applies the function of the same name, which can also be called on a mask directly: fill_ocean_holes!, fill_shelf_holes!, fill_small_shelf_patches! and fill_small_grounded_patches!.

MarkGapsPreprocess mirrors the refgeo_Hi > 0 test of the reference code: a gap is an ice-free cell where the reference geometry had ice, not a topological property of the mask. Place it after any hole-filling steps, so the gaps it marks are not reclassified afterwards. What happens in a gap is the gaps boundary condition.

grid = Grid(mask, z_draft, dx, dy;
            preprocess = [FillShelfHolesPreprocess(), MarkGapsPreprocess(reference_thickness)])

Laddie.MarkGapsPreprocess — Type
struct MarkGapsPreprocess{R<:(AbstractMatrix)} <: AbstractPreprocess

Mark ice-shelf gaps from a reference ice footprint: every open-ocean cell (0) where refgeo marks ice becomes a gap (4). This mirrors the refgeo_Hi > 0 test of the reference implementation — a gap is an ice-free cell where the reference geometry had ice, not a topological property of the mask.

refgeo may be a Bool matrix, or any numeric matrix in which positive entries mark ice (e.g. a reference ice thickness). It must match the size of the mask passed to Grid, since preprocessing runs before domain cropping — which is also what keeps a gap at the edge of the footprint from being cropped away before it exists.

Identifying gaps is a statement about geometry; what happens in a gap is the boundary condition, SinkGapsBC or ConnectedGapsBC. Place this step after any hole-filling steps in the preprocess list, so the gaps it marks are not reclassified afterwards.

grid = Grid(mask, z_draft, dx, dy; preprocess = [MarkGapsPreprocess(reference_thickness)])
Model(grid; forcing, boundary = BoundaryConditions(; gaps = ConnectedGapsBC()))

Fields

  • refgeo::AbstractMatrix: reference ice footprint (Bool, or numeric with positive entries marking ice)
