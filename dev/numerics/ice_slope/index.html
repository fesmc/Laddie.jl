Ice-base slope

The slope of the ice base, $\partial_x z_b$ and $\partial_y z_b$, drives the layer up the draft through the pressure gradient. It is part of the model's geometry, not of the Grid, because it depends on which cells are active, and is computed when the model is built, by Model(grid; gradient = ...):

  • JlGradient, the default, is mask-aware. At each shelf cell it uses only shelf-cell neighbours: centred differences where both neighbours are shelf, one-sided at ice fronts and grounding lines, zero where neither is. This avoids spurious slopes of order 0.2 from the drafts stored at ocean cells ($z_b = 0$) and grounded cells ($z_b$ = bed), which have nothing to do with the ice base.
  • PyGradient is the centred difference $(z_{b,i+1} - z_{b,i-1})/(2\Delta x)$ over all cells with no mask awareness, the stencil of LADDIE v1.1. Use it to compare against the v1 code.

API

Laddie.AbstractIceSlopeGradient — Type

Abstract supertype for ice-base slope (dzdx/dzdy) computation strategies. Pass a concrete instance as the gradient keyword to Model or build_isomip. The slope is part of the model's Geometry, not of the Grid: it depends on which cells are active.

source
Laddie.JlGradient — Type
JlGradient()

Mask-aware gradient (default): the ice-base slope at each shelf cell is computed using only shelf-cell neighbours, falling back to one-sided differences at ice fronts / grounding lines, and zero when no shelf neighbour exists. This avoids spurious slopes from the physically-incompatible z_draft values stored at ocean cells (z_draft=0) and grounded cells (z_draft=bed).

source
Laddie.PyGradient — Type
PyGradient()

v1-ported centred-difference gradient: (zb[i+1] − zb[i−1]) / (2 dx) applied uniformly over all cells with no mask awareness. Matches the LADDIE v1 v1.1 stencil exactly and should be used when comparing against the LADDIE v1 code output.
