Simulation end

A call to run! stops according to an end criterion, set once on the simulation as Simulation(model; stop = ...) or per call as run!(sim; until = ...). The keyword run!(sim; days = 30) is shorthand for until = FixedSimulationEnd(t_end = 30). Both criteria count from the start of the run! call, not of the simulation.

  • FixedSimulationEnd, the default: run a fixed duration t_end (days, 30 by default).
  • SteadyStateEnd: stop once the cavity reaches a quasi-steady state, or after t_end days (365 by default), whichever comes first. The run is steady when the relative change in the mean melt rate over floating ice between two daily samples falls below tol,

    \[\frac{|\bar m_{k+1} - \bar m_k|}{|\bar m_k|} < \mathrm{tol}.\]

    tol is relative, so it means the same thing in a warm cavity (melt of order 100 m yr⁻¹) and a cold one (order 1 m yr⁻¹). Daily sampling is cheap, insensitive to the leapfrog computational mode, and independent of the run length.
run!(sim; until = SteadyStateEnd(tol = 1e-3, t_end = 365.0))

API

Laddie.AbstractSimulationEnd — Type

Abstract supertype for the stopping criterion of run!. Pass a concrete instance as Simulation(model; stop = ...) or run!(sim; until = ...): FixedSimulationEnd (run a set duration) or SteadyStateEnd (stop once the solution settles).

source
Laddie.FixedSimulationEnd — Type
struct FixedSimulationEnd{T} <: AbstractSimulationEnd

Stop after a fixed simulated duration t_end (days, the duration of this run! call). This is the default and exactly reproduces run!(sim; days = t_end).

Select via Simulation(model; stop = FixedSimulationEnd(t_end = 30.0)) or run!(sim; until = FixedSimulationEnd(t_end = 30.0)).

Fields

  • t_end::Any: duration of the run! call (days, default 30)

Laddie.SteadyStateEnd — Type
struct SteadyStateEnd{T} <: AbstractSimulationEnd

Stop early once the cavity reaches a quasi-steady state, or after t_end days, whichever comes first. Steadiness is detected when the relative change in the domain-mean basal melt rate (over floating ice) between successive diagnostic samples falls below tol:

\[|\bar{m}_{k+1} - \bar{m}_k| / |\bar{m}_k| < \mathrm{tol}\]

tol is dimensionless, so it means the same thing in a warm cavity (melt of order 100 m yr⁻¹) and a cold one (order 1 m yr⁻¹). Samples are taken once per simulated day (not every step), which is cheap, robust to the leapfrog computational mode, and independent of the run length. t_end is a safety cap on the duration of the run! call.

Select via run!(sim; until = SteadyStateEnd(tol = 1e-3, t_end = 365.0)).

Fields

  • tol::Any: relative change in the mean melt rate between daily samples below which the run stops (default 1e-3)

  • t_end::Any: cap on the duration of the run! call (days, default 365)
