Published setups

Aliases for the runs of earlier LADDIE versions: Params<Setup>v1|v2 returns the Params of a run, and any keyword overrides a field, as in ParamsFRISv1(; H_min = 3.0). Simulation<Setup>v1|v2(backend = CPU(); FT, datadir, params, simulation_kwargs...) builds the whole run from the geometry it left behind under datadir (default papers/ in the package root, not part of the repository). params defaults to the run's Params alias, and any other keyword goes to Simulation, overriding the setup's dt and stop.

Where a paper and the code that produced its results disagree, the values follow the code (the run's own configuration file), and the differences are listed below. LADDIE v2 runs on an unstructured mesh with forward–backward Runge–Kutta time stepping, and Laddie.jl on a C-grid with leapfrog, so the v2 aliases match v2's parameters, not its numerics. Every alias pins integrator = LeapfrogIntegrator(; nu = 0.8).

Parameters

LADDIE v1. Every v1 config shares Jenkins (1991) transfer coefficients (TurbulentGamTMelting), C_d_top = 1.1e-3, μ = 2.5, max_detrainment = 0.5, v_cut = 1.414, H_init = 10, dT_init = 0, f = −1.37 × 10⁻⁴ s⁻¹, the prescribed viscosity A_h, centred momentum advection, advective tracer and momentum forms, and v1's ice-slope stencil CentredIceSlope.

Simulations

All files are under datadir. The v1 runs use v1's walls (its slip = 1: no slip in the viscosity, V1WallAdvection), zero-gradient inflow at the ice front and T_ice_farfield = -25 °C. The v2 runs use v2's walls (slip factor 1, no momentum across walls), zero-gradient inflow and UPSY's default ice temperature, 270 K (−3.15 °C); their shelf is the ice that floats in v2's output remapped from its mesh to a regular grid.

The two v1 Amundsen Sea runs. The config reads a 500 m geometry with coarsen = 2, but the v1 code sets the grid spacing before coarsening and never updates it. The run was therefore on a 1 km grid with Δx = 500 m in every derivative, and so is SimulationASEv1 (Grid(…, 500, 500) on the 1 km cells). SimulationASEv1Theoretical is the consistent 1 km run.

The MISOMIP+ simulations are the initial LADDIE spin-up of coupled UFEMISM–LADDIE runs, run standalone as a sanity check.

Where the papers differ

  • All v1 runs. μ = 2.5, as in every bundled v1 config; Lambert et al. (2023, Table 1) state μ = 0.5. The layer starts at the ambient temperature (dT_init = 0, as in the configs); the paper starts it 0.1 °C below. max_detrainment = 0.5 and v_cut = 1.414 are code values the paper does not mention.
  • Crosson–Dotson. The run behind the stored output lasted 50 days (averaged over days 45–50); the paper reports a 30-day equilibration.
  • Filchner–Ronne. The paper builds the 1 km grid by averaging 2 × 2 BedMachine cells. If that was done with the v1 code's coarsen, the run used Δx = 500 m in its derivatives (as the v1 Amundsen Sea run); the stored file cannot tell, so Δx = 1 km is used.
  • Pine Island, v1. The paper gives only the deep temperature and the thermocline depth; the thermocline scale (250 m), S0 and drho0 are those of the Crosson–Dotson profile it says this one adapts.
  • Amundsen Sea, v1 and v2. The configs set f = −1.37 × 10⁻⁴ s⁻¹; Lambert et al. (2026) state −1.34 × 10⁻⁴ s⁻¹ for both model versions. The paper gives no viscosity or diffusivity for the v1 run.
  • All v2 runs. UPSY hard-wires ρ₀ = 1027 kg m⁻³ and L = 3.335 × 10⁵ J kg⁻¹, used here; Lambert et al. (2026, Table 1) state 1028 and 3.34 × 10⁵. The ice temperature of the standalone runs is UPSY's default 270 K, not v1's −25 °C.
  • ISOMIP+, pan-Antarctic. The configs set the viscosity coefficient to 0.1 and K_h = 1; Table 1 of the paper lists 1 and 4. The pan-Antarctic buoyancy floor of 0.02 kg m⁻³ is four times that of the other runs.
  • Pine Island, 120 m. The paper says the configuration is that of its Table 1 (viscosity 1, K_h = 4); the config uses 0.1 and 0.1.
  • MISOMIP+. The config sets 1.5 °C at depth; the paper describes the forcing of Jesse et al. (2025), with 1.2 °C.
  • Ice-shelf gaps. The paper fixes the surface at −1.8 °C; UFEMISM 'TANH' puts it at the freezing point of 34 psu, −1.865 °C.
