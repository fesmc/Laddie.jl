Coriolis parameter

At ice-shelf scale, rotation steers the meltwater into boundary currents rather than letting it flow straight up-slope — visible in the flow-speed plot of the ISOMIP+ warm run.

The Coriolis parameter $f$ enters the momentum equations only as the scalar in $-f\,\hat{\mathbf{k}} \times \mathbf{u}$, which does not change when the horizontal axes are rotated. So the orientation of the grid relative to true north never matters; only the latitude does, through $f = 2\Omega \sin\varphi$. It is selected with Params(; coriolis = ...):

  • CoriolisParameter0D, the default: an f-plane with $f$ given directly, $-1.37\times10^{-4}$ s⁻¹ (the ISOMIP+ value, 69.95 °S) by default.
  • CoriolisParameter2D: $f$ from latitude. A scalar latitude is still an f-plane, stated geographically; its default reproduces the f-plane default to the last bit. A full-domain latitude matrix, the size of the mask, gives a genuine β-plane, and Model crops it with the mask.

Across the Antarctic shelves $f$ runs from $-1.32\times10^{-4}$ s⁻¹ at 65 °S to $-1.44\times10^{-4}$ at 80 °S, roughly a 9 % spread. The Rossby radius scales as $1/f$, so a large domain feels it even though the range looks narrow.

API

Laddie.AbstractCoriolisParameter — Type

Supertype of the Coriolis-parameter options. Select with Params(; coriolis = ...); see CoriolisParameter0D (an f-plane) and CoriolisParameter2D (f from latitude).

source
Laddie.CoriolisParameter0D — Type
struct CoriolisParameter0D{FT} <: AbstractCoriolisParameter

f-plane: one Coriolis parameter over the whole domain, given directly.

The default is the ISOMIP+ value $f = -1.37\times10^{-4}$ s⁻¹, which corresponds to 69.95 °S.

Select via Params(; coriolis = CoriolisParameter0D(-1.4e-4)).

Fields

  • f::Any: Coriolis parameter (s⁻¹, default the ISOMIP+ value -1.37e-4)
source
Laddie.CoriolisParameter2D — Type
struct CoriolisParameter2D{L} <: AbstractCoriolisParameter

Coriolis parameter from latitude, $f = 2Ω\sin φ$.

lat is in degrees north (negative in the Southern Hemisphere) and may be

  • a scalar — still an f-plane, but stated geographically rather than as a raw frequency. The default reproduces CoriolisParameter0D's default exactly, so swapping one for the other changes nothing until lat is set.
  • a full-domain matrix the same size as mask — a genuine β-plane. Model crops it alongside the mask, so m.f is always a grid-shaped field.

Across the Antarctic shelves f runs from −1.32e-4 at 65 °S to −1.44e-4 at 80 °S, roughly a 9 % spread; the Rossby radius scales as 1/f, so a large domain feels it even though the range looks narrow.

Params(; coriolis = CoriolisParameter2D(-75.0))      # f-plane at 75°S
Params(; coriolis = CoriolisParameter2D(lat_matrix)) # varying with latitude

Fields

  • lat::Any: latitude in degrees north: a scalar (f-plane) or a full-domain matrix the size of mask
