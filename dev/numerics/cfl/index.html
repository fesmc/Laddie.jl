CFL number

The diagnosed CFL is a measurement of the current state at the current step,

\[C = \Delta t\,\max_{\text{active cells}}\left(\frac{|u| + c}{\Delta x} + \frac{|v| + c}{\Delta y}\right), \qquad c = \sqrt{g\,\delta\rho\,H},\]

covering advection and internal gravity waves only (there is no viscous term). It is computed in one of two ways, Simulation(model; cfl = ...):

  • ExactCFL, the default, takes the maximum cell by cell, at the cost of one kernel pass.
  • ConservativeCFL adds up the separate domain maxima of $|U|$, $|V|$ and $c$. The worst velocity and the worst wave speed rarely occur in the same cell, so it reads higher.

run! measures $C$ at its check points: every ncheck steps, or more often on short runs. It is measured with or without the adaptive controller, and appears in the progress display as dt [s] / CFL and in each dt-change log line.

Both diagnostics feed the same cfl_target of AdaptiveDt. Since ConservativeCFL reads higher, the same target gives a smaller, safer step with it than with ExactCFL.

Worst-case CFL

A flow starting from rest has $C \approx 0$, which says nothing about the flow it will develop. Before the first step, the worst-case CFL uses the speed cap $v_\text{cut}$ in place of the velocity. The adaptive controller checks the initial dt against it, which can only shrink the step, and run! warns when it exceeds 1, whatever the time stepper.

API

Laddie.AbstractCFL — Type

Abstract supertype for how the in-loop CFL number is computed (for the progress display and for AdaptiveDt). Pass a concrete instance as Simulation(model; cfl = ...): ExactCFL (the default) or ConservativeCFL.

source
Laddie.ExactCFL — Type
struct ExactCFL <: AbstractCFL

Per-cell CFL: interpolates U and V to T-points, computes the CFL at every active cell, and returns the maximum (the default). Tighter than ConservativeCFL at the cost of one kernel pass.

source
Laddie.ConservativeCFL — Type
struct ConservativeCFL <: AbstractCFL

Conservative CFL estimate: takes max|U|, max|V|, and max c independently over the active domain, then adds them. This overestimates the true CFL (the worst velocity and worst wave speed rarely occur at the same cell) but avoids a per-cell kernel pass.
