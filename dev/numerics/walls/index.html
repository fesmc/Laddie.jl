Wall slip

Grounding lines (mask value 2) and land (mask value 1: exposed bedrock, islands and the outer border ring) are zero-flux walls. The condition on the tangential momentum at each wall is one slip factor $s$ on the faces it bounds, with the convention of NEMO (rn_shlat): the velocity behind the wall is taken as a ghost $(1 - s)\,u$. The two kinds of wall are set independently, with BoundaryConditions(; grounding_line = ..., land = ...):

free slip, $s = 0$partial slipno slip, $s = 2$
grounding line, AbstractGroundingLineBCFreeSlipGLPartialSlipGL(s), default s = 1NoSlipGL
land, AbstractLandBCFreeSlipLandPartialSlipLand(s), default s = 1NoSlipLand

What $s$ means

Take a $u$-point next to a wall. On the C-grid the wall is the face between the two rows of T-cells, half a grid spacing $\Delta$ away; the next $u$-point, a full $\Delta$ away, is behind the wall. The viscous flux through the wall face is

\[A\,H\,\frac{(1 - s)\,u - u}{\Delta^2} = -s\,A\,H\,\frac{u}{\Delta^2},\]

the same as a velocity gradient $u/\delta$ with $\delta = \Delta/s$. So $s$ sets where the velocity is zero:

$s$$u = 0$ at
0nowherefree slip: the wall exerts no stress
1one $\Delta$ behind the wall, at the next $u$-pointpartial slip; LADDIE v2's wall (the default)
2the wall face, $\Delta/2$ awayno slip

The kernels form it from the velocity stored behind the wall, which is zero, so the plain stencil already holds $s = 1$; they add the remaining $s - 1$. Under NonlinearLateralViscosity the ghost enters the shear-scaled coefficient as well, so its wall stress grows as $s^2$.

The same ghost forms the momentum carried across a wall face by the advection, unless wall momentum advection says otherwise.

At a coastline corner whose stencil touches both grounded ice and exposed rock, the grounding-line condition takes precedence, so each wall face gets exactly one slip factor.

LADDIE v1 and v2

LADDIE v2 treats grounded and ice-free land neighbours as ordinary cells with zero velocity, one grid spacing away (laddie_velocity.f90:259-267), and carries no momentum across them. This is the default, $s = 1$ with NoWallAdvection. v2 calls it "no slip" (Lambert et al., 2026); in this convention it is partial slip.

LADDIE v1 describes its walls as NEMO-like partial slip with a factor between 0 (free slip) and 2 (no slip), and its published runs use 1 (Lambert et al., 2023). Its code, however, adds the factor to a viscous stencil that already holds the stored zero, so its viscous wall is one step stronger than labelled: $s = 1$ is no slip there. In the advection the factor is used as labelled. Reproducing v1 therefore takes V1WallAdvection:

# LADDIE v1 (slip = 1): no slip in the viscosity, partial slip in the advection
BoundaryConditions(; grounding_line = NoSlipGL(), land = NoSlipLand(),
                   wall_advection = V1WallAdvection())

# LADDIE v2: the defaults
BoundaryConditions()

API

Laddie.AbstractGroundingLineBC — Type

Abstract supertype for the momentum boundary condition at grounding-line walls (mask value 2). Pass a concrete instance as BoundaryConditions(; grounding_line = ...): PartialSlipGL (the default, PartialSlipGL(1.0), LADDIE v2's wall), NoSlipGL or FreeSlipGL.

Walls bordering exposed rock are governed separately by AbstractLandBC.

source
Laddie.NoSlipGL — Type
struct NoSlipGL <: AbstractGroundingLineBC

No-slip momentum boundary condition at the grounding line: the tangential velocity vanishes at walls bordering grounded ice (mask value 2), i.e. at the face between the last shelf cell and the grounded cell. Implemented as a slip factor of 2 on grounding-line faces. Land walls (mask value 1) are governed independently by BoundaryConditions.land.

This is the viscous wall of LADDIE v1 as published (slip = 1 in its configs: v1 adds its factor to a stencil that already holds one unit of wall stress); see V1WallAdvection for its advective part. It is stronger than LADDIE v2's "no slip", which is PartialSlipGL(1.0).

Select via BoundaryConditions(; grounding_line = NoSlipGL()).

source
Laddie.FreeSlipGL — Type
struct FreeSlipGL <: AbstractGroundingLineBC

Free-slip momentum boundary condition at the grounding line: slip factor 0 at walls bordering grounded ice, so the wall exerts no viscous stress on the flow.

Select via BoundaryConditions(; grounding_line = FreeSlipGL()).

source
Laddie.PartialSlipGL — Type
struct PartialSlipGL{FT} <: AbstractGroundingLineBC

Partial-slip momentum boundary condition at the grounding line, with a slip factor between 0 (free slip) and 2 (no slip): the velocity behind the wall is taken as (1 - factor)·u.

PartialSlipGL(1.0) is the default and LADDIE v2's wall: v2 treats a grounded neighbour as an ordinary cell with zero velocity, one grid spacing away (laddie_velocity.f90:259-267), which v2 calls "no slip" (Lambert et al. (2026)).

Select via BoundaryConditions(; grounding_line = PartialSlipGL(1.0)) (the default).

Fields

  • factor::Any: slip factor, from 0 (free slip) to 2 (no slip)
source
Laddie.AbstractLandBC — Type

Abstract supertype for the momentum boundary condition at land walls (mask value 1: exposed bedrock, islands, and the outer border ring). Pass a concrete instance as BoundaryConditions(; land = ...): PartialSlipLand (the default, PartialSlipLand(1.0), LADDIE v2's wall), NoSlipLand or FreeSlipLand.

The grounding line is governed separately by AbstractGroundingLineBC; at a coastline corner whose stencil touches both grounded ice and exposed rock, the grounding-line condition takes precedence (the land wall indicators exclude faces already flagged as grounding line), so each wall face gets exactly one slip factor.

source
Laddie.NoSlipLand — Type
struct NoSlipLand <: AbstractLandBC

No-slip momentum boundary condition at land walls: the tangential velocity vanishes at walls bordering exposed bedrock (mask value 1), which includes islands and ice-free coastline inside the domain as well as the outer border ring. Implemented as a slip factor of 2 on land faces. See NoSlipGL for its relation to LADDIE v1 and v2.

Select via BoundaryConditions(; land = NoSlipLand()).

source
Laddie.FreeSlipLand — Type
struct FreeSlipLand <: AbstractLandBC

Free-slip momentum boundary condition at land walls: slip factor 0 at walls bordering exposed bedrock, so the wall exerts no viscous stress on the flow.

Select via BoundaryConditions(; land = FreeSlipLand()).

Laddie.PartialSlipLand — Type
struct PartialSlipLand{FT} <: AbstractLandBC

Partial-slip momentum boundary condition at land walls, with a slip factor between 0 (free slip) and 2 (no slip). PartialSlipLand(1.0) is the default and LADDIE v2's wall, where ice-free land cells, like grounded ones, hold zero velocity; see PartialSlipGL.

Select via BoundaryConditions(; land = PartialSlipLand(1.0)) (the default).

Fields

  • factor::Any: slip factor, from 0 (free slip) to 2 (no slip)
