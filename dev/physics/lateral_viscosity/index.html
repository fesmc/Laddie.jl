Lateral viscosity

The momentum equations carry a lateral viscous term, a thickness-weighted Laplacian of the velocity. Its coefficient is selected with Params(; lateral_viscosity = ...):

  • PrescribedLateralViscosity: one global coefficient Params.A_h (6 m² s⁻¹ by default), as LADDIE v1 does.
  • NonlinearLateralViscosity, the default: a Smagorinsky-type coefficient, as LADDIE v2 does, which is near zero in smooth flow and large where the shear is strong. At each interior face it is

    \[A_h^{\mathrm{eff}} = \frac{C_{\mathrm{visc}}}{100}\,\Delta\,\lVert\delta\mathbf{u}\rVert,\]

    with $\Delta$ the grid spacing across the face and $\lVert\delta\mathbf{u}\rVert$ the magnitude of the velocity difference across it. C_visc is dimensionless and resolution-independent, so it is directly comparable to the v2 configuration value, but not to A_h. C_visc/100 plays the role of a squared Smagorinsky constant; the default 0.1, v2's Antarctic value, corresponds to $C_s \approx 0.032$ (v2's MISMIP+ value 10 to 0.32).

The grounding-line and land walls carry the scheme's own coefficient, with the neighbour replaced by the ghost velocity $(1 - s)\,u$ of the slip factor $s$. With the default $s = 1$ the ghost is zero, as in the v2 reference, which treats grounded and land neighbours as ordinary cells at rest (laddie_velocity.f90); only at the border of its mesh does v2 apply the bare C%laddie_viscosity as a constant, which Laddie.jl has no counterpart of. How strongly the walls brake the flow is the slip factor, set separately (see Wall slip). Two things are not affected by this choice:

  • Tracer diffusion. The tracer diffusivity Params.K_h is always a constant.
  • Shear entrainment. HollandEntrainment uses A_h and K_h as its length scale either way.
C-grid staggering

The v2 reference collocates U and V at triangle centres, so its velocity difference dUabs is direct. On the staggered C-grid the cross-component is first interpolated onto this component's points, with the 4-point average the quadratic drag uses for the speed (ip_half(jm_half(V)) for the U equation, jp_half(im_half(U)) for V). The difference is the full vector $\lVert\delta\mathbf{u}\rVert = \sqrt{\delta U^2 + \delta V^2}$, so one isotropic coefficient serves both components of a face.

The time level of the thickness that weights the Laplacian is a separate, numerical choice: Laplacian weights. There is no viscous constraint on the time step, so a large viscosity on a fine grid is not caught by the CFL controller.

API

Laddie.AbstractLateralViscosity — Type

Abstract supertype for lateral (horizontal) momentum viscosity parameterisations. Pass a concrete instance as Params(; lateral_viscosity = ...): NonlinearLateralViscosity (shear-scaled, as in LADDIE v2, the default) or PrescribedLateralViscosity (constant coefficient).

The momentum equations carry the lateral friction ∇·(A_h H ∇u). Tracer diffusivity Params.K_h is always a constant.

source
Laddie.PrescribedLateralViscosity — Type
struct PrescribedLateralViscosity <: AbstractLateralViscosity

Constant-coefficient Laplacian lateral viscosity, Params.A_h everywhere, as in LADDIE v1 (Lambert et al. 2023, Eqs. 2–3). Wall stress relative to an interior face is set by the slip factor of BoundaryConditions.

Select via Params(; lateral_viscosity = PrescribedLateralViscosity()).

source
Laddie.NonlinearLateralViscosity — Type
struct NonlinearLateralViscosity{FT} <: AbstractLateralViscosity

Shear-scaled (Smagorinsky-type) lateral viscosity of the LADDIE v2 code (Lambert et al. 2026): at each face

A_h^eff = C_visc/100 Δ ‖δu‖,

with Δ the grid spacing across the face and ‖δu‖ the magnitude of the velocity-difference vector across it. C_visc is dimensionless and resolution-independent, comparable to v2's configuration value but not to Params.A_h, which plays no part here. Walls take the ghost velocity of the slip factor. See Lateral viscosity.

Select via Params(; lateral_viscosity = NonlinearLateralViscosity(0.1)) (the default).

Fields

  • C_visc::Any = 0.1: dimensionless coefficient, the reference C%laddie_viscosity (default 0.1, its Antarctic value; its MISMIP+ config uses 10)
