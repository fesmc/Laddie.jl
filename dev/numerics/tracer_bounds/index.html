Tracer bounds

After every tracer step, the layer temperature and salinity can be clamped to a fixed range inside the active domain, Params(; tracer_bounds = ...):

optioneffect
TracerBounds$T \in [T_\min, T_\max]$, $S \in [S_\min, S_\max]$ (defaults −5 … 5 °C, 32 … 36 psu)
NoTracerBounds (default)none, as in LADDIE v2

The bounds are a stability safeguard, not physics. With the tracers pinned the melt rate stays finite, so a diverging run is hidden from the blow-up check. Widen them for fresher settings such as Greenland fjords; an infinite bound switches that side off. Under SmoothKinks the corners of the clamp are smoothed over ε_T and ε_S (see Kinks).

API

Laddie.AbstractTracerBounds — Type

Abstract supertype for bounds on the layer temperature and salinity, applied inside the active domain after every tracer step. Pass a concrete instance as Params(; tracer_bounds = ...): NoTracerBounds (the default) or TracerBounds.

Bounds are a stability safeguard, not physics: LADDIE v2 has no counterpart, it assigns T and S only from the flux-form integration. They carry a real cost: with the tracers pinned the melt rate stays finite, so a diverging run is hidden from the blow-up check. The clamp is an instantaneous adjustment; with SmoothKinks its corners are smoothed by ε_T and ε_S.

source
Laddie.NoTracerBounds — Type
struct NoTracerBounds <: AbstractTracerBounds

Leave the layer temperature and salinity unbounded: they are set by their budgets alone, as in LADDIE v2 (the default).

Select via Params(; tracer_bounds = NoTracerBounds()).

source
Laddie.TracerBounds — Type
struct TracerBounds{FT} <: AbstractTracerBounds

Clamp the layer temperature to [T_min, T_max] and the salinity to [S_min, S_max] inside the active domain after every tracer step. Outside tmask the tracers stay zero. Widen the bounds for fresher settings such as Greenland fjords; an infinite bound switches that side off.

julia> Params(; tracer_bounds = TracerBounds(; T_max = 2.0, S_min = 30.0)).tracer_bounds
TracerBounds{Float64}(-5.0, 2.0, 30.0, 36.0)

Fields

  • T_min::Any: lower temperature bound (°C, default -5)

  • T_max::Any: upper temperature bound (°C, default 5)

  • S_min::Any: lower salinity bound (psu, default 32)

  • S_max::Any: upper salinity bound (psu, default 36)
