Published setups

Aliases for the runs of earlier LADDIE versions: Params<Setup>v1|v2 returns the Params of a run, and Simulation<Setup>v1|v2 builds the whole run from the geometry it left behind under papers/ (not part of the repository). Where a paper and the code that produced its results disagree, the values follow the code and the docstring says how the paper differs. LADDIE v2 runs on an unstructured mesh with forward–backward Runge–Kutta time stepping, so its aliases match its parameters, not its numerics.

Laddie.ParamsCrossonDotsonv1 — Function
ParamsCrossonDotsonv1(; FT = Float64, kwargs...)

Params of the Crosson–Dotson run of LADDIE v1.0 (Lambert et al. 2023, Table 2: Δx = 500 m), with any field overridden by kwargs. A_h = K_h = 25, H_min = 2.8, u_tide = 0.01, C_d_top = 1.1e-3, Jenkins (1991) transfer coefficients.

Paper differs

The entrainment parameter is μ = 2.5 here, as in every bundled v1 config; Lambert et al. (2023, Table 1) state μ = 0.5. The layer starts at the ambient temperature (dT_init = 0, as in the configs); the paper starts it 0.1 °C below. max_detrainment = 0.5 and v_cut = 1.414 are code values the paper does not mention.

See also SimulationCrossonDotsonv1.

Laddie.ParamsASEv1 — Function
ParamsASEv1(; FT = Float64, kwargs...)

Params of the LADDIE v1 Amundsen Sea run that Lambert et al. (2026, Sect. 3.1) compare v2 against, from its config (results/laddie1/ASE/config_ASE.toml): A_h = 20, K_h = 4, H_min = 1, u_tide = 0.01, C_d_top = 1.1e-3.

Paper differs

The config sets f = −1.37 × 10⁻⁴ s⁻¹; Lambert et al. (2026) state −1.34 × 10⁻⁴ s⁻¹ for both model versions. The paper gives no viscosity or diffusivity for this run.

See also SimulationASEv1 and SimulationASEv1Theoretical.

Laddie.SimulationCrossonDotsonv1 — Function
SimulationCrossonDotsonv1(backend = CPU(); FT = Float64, datadir, params, simulation_kwargs...)

The Crosson–Dotson run of LADDIE v1.0 (Lambert et al. 2023), on the 500 m domain stored in datadir/lambert-2023/data/CrossDots_0.5_tanh_Tdeep0.4_ztcl-500_050.nc.

  • forcing: v1 'tanh' profile, T from the surface freezing point (S0 = 34) to 0.4 °C, thermocline at −500 m with scale 250 m, drho0 = 0.01 (fitted to the file's ambient fields to 1e−4 °C); T_ice_base = -25 °C
  • dt = 120 s, 50 days, Robert–Asselin nu = 0.8
  • v1 walls (partial slip 1), the v1 ice-slope stencil PyGradient

params defaults to ParamsCrossonDotsonv1; other keywords go to Simulation and override dt, nu and stop.

Paper differs

The run behind the stored output lasted 50 days (averaged over days 45–50); the paper reports a 30-day equilibration. See also ParamsCrossonDotsonv1.

Laddie.SimulationFRISv1 — Function
SimulationFRISv1(backend = CPU(); FT = Float64, datadir, params, simulation_kwargs...)

The Filchner–Ronne run of LADDIE v1.0 (Lambert et al. 2023), on the 1 km domain stored in datadir/lambert-2023/data/FRIS_1.0_linear_S134.8_T1-2.3_720.nc.

  • forcing: v1 'linear' profile, T from the surface freezing point to −2.3 °C and S from 34.5 to 34.8 psu at −2000 m (matches the file's ambient fields to round-off); T_ice_base = -25 °C
  • dt = 240 s, 720 days, Robert–Asselin nu = 0.8
  • v1 walls (partial slip 1), PyGradient

params defaults to ParamsFRISv1; other keywords go to Simulation.

Note

The paper builds the 1 km grid by averaging 2 × 2 BedMachine cells. If that was done with the v1 code's coarsen, the run used Δx = 500 m in its derivatives (see SimulationASEv1); the stored file cannot tell, so Δx = 1 km is used here.

Laddie.SimulationPIGv1 — Function
SimulationPIGv1(backend = CPU(); FT = Float64, datadir, params, simulation_kwargs...)

The Pine Island run of LADDIE v1.0 (Lambert et al. 2023, App. C), on the 500 m domain stored in datadir/lambert-2023/data/PIG.nc.

  • geometry: the file holds no mask, so it is rebuilt from the stored ice thickness and bed by flotation with BedMachine's densities (917 and 1027 kg m⁻³)
  • forcing: v1 'tanh' as Crosson–Dotson, but 1.0 °C at depth and the thermocline at −450 m; T_ice_base = -25 °C
  • dt = 120 s, 30 days, Robert–Asselin nu = 0.8
  • v1 walls (partial slip 1), PyGradient

params defaults to ParamsPIGv1; other keywords go to Simulation.

Note

The paper gives only the deep temperature and thermocline depth; the thermocline scale (250 m), S0 and drho0 are taken from the Crosson–Dotson profile it says this one adapts.

Laddie.SimulationASEv1 — Function
SimulationASEv1(backend = CPU(); FT = Float64, datadir, params, simulation_kwargs...)

The LADDIE v1 Amundsen Sea run of Lambert et al. (2026, Sect. 3.1) as it was run, on the 1 km domain stored in datadir/lambert-2026/results/laddie1/ASE/output_000020.nc.

The config reads a 500 m geometry with coarsen = 2, but the v1 code sets the grid spacing before coarsening and never updates it. The run was therefore on a 1 km grid with Δx = 500 m in every derivative, and so is this simulation: Grid(…, 500, 500) on the 1 km cells. SimulationASEv1Theoretical is the consistent 1 km run.

  • forcing: v1 'tanh', surface freezing point (S0 = 34) to 1.0 °C, thermocline at −450 m with scale 100 m, drho0 = 0.01; T_ice_base = -25 °C
  • dt = 30 s, 20 days, Robert–Asselin nu = 0.8
  • v1 walls (partial slip 1), PyGradient

params defaults to ParamsASEv1; other keywords go to Simulation.

Laddie.SimulationMISOMIPGapsv2 — Function
SimulationMISOMIPGapsv2(backend = CPU(); ocean = :ocean3, gaps = SinkGapsBC(), FT = Float64,
                        datadir, params, simulation_kwargs...)

The initial LADDIE spin-up of the coupled runs of Jesse et al. (2026), standalone, as a sanity check. Jesse et al.'s spun-up geometry is not bundled (their output is on the mesh only); this uses the MISOMIP+ spin-up of Lambert et al. (2026) instead, as in SimulationMISOMIPv2, whose grounding line also sits near x = 450 km.

  • ocean: :ocean1, :ocean2 or :ocean3, deep temperature −1, 0 or 1 °C under a thermocline at 450 m (UFEMISM 'TANH', which keeps the density profile identical across the three, as the paper requires); T_ice_base = -3.15 °C
  • gaps: SinkGapsBC (the paper's "sink", LADDIE's default) or ConnectedGapsBC ("connected"); without gaps in the initial geometry both give the same run
  • dt = 100 s, 20 days

params defaults to ParamsMISOMIPGapsv2; other keywords go to Simulation.

Paper differs

The paper fixes the surface at −1.8 °C; UFEMISM 'TANH' puts it at the freezing point of 34 psu, −1.865 °C.
