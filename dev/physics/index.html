Physics

LADDIE models the thin, buoyant meltwater layer that forms directly beneath an ice shelf. Melting the ice base releases cold but fresh water; freshness wins over coldness, so the meltwater is buoyant, pools against the sloping ice draft, and drives a circulation — the ice pump. Rather than resolving the full 3-D cavity, LADDIE collapses that layer into a single depth-integrated layer and evolves five 2-D fields:

fieldmeaningC-grid location
$H$layer thickness (m)cell centre
$U, V$depth-averaged velocity (m/s)cell faces
$T, S$depth-averaged temperature (°C) / salinity (psu)cell centre

Governing balances

The model integrates vertically-averaged shallow-water equations with thermodynamics. Schematically:

\[\frac{\partial H}{\partial t} = -\nabla\!\cdot(\mathbf{u}\,H) + \dot{m} + \dot{e}\]

\[\frac{\partial (H\mathbf{u})}{\partial t} = -\nabla\!\cdot(\mathbf{u}\,H\,\mathbf{u}) - f\,H\,\mathbf{u}^{\perp} - g\,H\,\nabla(H\,\Delta\rho') + (\text{draft pressure}) - C_d\,|\mathbf{u}|\mathbf{u} + A_h\,\nabla^2(H\mathbf{u})\]

\[\frac{\partial (HT)}{\partial t} = -\nabla\!\cdot(\mathbf{u}\,H\,T) + \dot{e}\,T_a + \dot{m}\,T_b - \gamma_T (T - T_b) + K_h\nabla^2 T\]

\[\frac{\partial (HS)}{\partial t} = -\nabla\!\cdot(\mathbf{u}\,H\,S) + \dot{e}\,S_a + K_h\nabla^2 S \qquad(\text{ice is salt-free})\]

The equation reference gives every term as published in Lambert et al. (2023) and as integrated by the kernels.

Closures

Each closure is a family of types under one abstract supertype, and a run picks one member by passing an instance to Params, BoundaryConditions or the forcing. The pages of this section describe one family each:

pageabstract typeselected withdefault

Ice conductionAbstractIceConductionParams(; ice_conduction)HollandJenkinsConduction()

ConvectionAbstractConvectionSchemeParams(; convection_scheme)ResetToAmbient(0.005)

Ocean forcingAbstractOceanForcingModel(grid; forcing)—
Ice-shelf gapsAbstractGapsBCBoundaryConditions(; gaps)SinkGapsBC()

The defaults reproduce Python LADDIE v1.x, against which Laddie.jl is validated, except for the no-slip walls (see Wall slip) and the flux-form tracer step (see Tracer form), which follow LADDIE v2. Options marked experimental log a warning when constructed.

The ice forcing has a single member, PrescribedIceForcing, which supplies the ice temperature $T_i$ used by the melting and ice conduction closures.
