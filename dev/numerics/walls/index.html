Wall slip

Grounding lines (mask value 2) and land (mask value 1: exposed bedrock, islands and the outer border ring) are zero-flux walls. The condition on the tangential momentum at each wall is one slip factor $s$ on the faces it bounds, with the LADDIE v1 convention: $s = 0$ is free slip, $s = 2$ no slip, and anything in between partial slip. The two kinds of wall are set independently, with BoundaryConditions(; grounding_line = ..., land = ...):

free slip, $s = 0$partial slipno slip, $s = 2$ (default)
grounding line, AbstractGroundingLineBCFreeSlipGLPartialSlipGL(s)NoSlipGL
land, AbstractLandBCFreeSlipLandPartialSlipLand(s)NoSlipLand

The slip factor enters the kernels exactly as in the LADDIE v1 stencils:

  • in the lateral viscosity, the wall-face flux is $-(1 + s)\,H u/\Delta^2$: the zero velocity stored beyond the wall, plus an extra wall drag $s\,H u/\Delta^2$, which always scales with the global Params.A_h (see Lateral viscosity);
  • in the momentum advection, through a ghost velocity $(1 - s)\,u$ at the wall — unless wall momentum advection is switched off.

So $s = 0$ removes the extra wall drag rather than making the wall exactly stress-free; the naming follows the reference.

At a coastline corner whose stencil touches both grounded ice and exposed rock, the grounding-line condition takes precedence, so each wall face gets exactly one slip factor.

Reproducing LADDIE v1 and v2

The no-slip default follows LADDIE v2, where a no-slip grounding line improves melt patterns near the grounding line compared with observations. LADDIE v1 applies one factor, $s = 1$, to every wall:

# LADDIE v1
BoundaryConditions(; grounding_line = PartialSlipGL(1.0), land = PartialSlipLand(1.0))

# LADDIE v2: no slip in the viscosity, no momentum across walls
BoundaryConditions(; wall_advection = NoWallAdvection())

API

Laddie.AbstractGroundingLineBC — Type

Abstract supertype for the momentum boundary condition at grounding-line walls (mask value 2). Pass a concrete instance as BoundaryConditions(; grounding_line = ...): NoSlipGL (the default), FreeSlipGL or PartialSlipGL.

Walls bordering exposed rock are governed separately by AbstractLandBC.

source
Laddie.NoSlipGL — Type
struct NoSlipGL <: AbstractGroundingLineBC

No-slip momentum boundary condition at the grounding line (the default): the tangential velocity vanishes at walls bordering grounded ice (mask value 2). Implemented as a slip factor of 2 on grounding-line faces. Land walls (mask value 1) are governed independently by BoundaryConditions.land.

Motivated by LADDIE v2.0 (Lambert et al. (2026)), where a no-slip grounding-line condition improves melt patterns near the grounding line compared to observations.

Select via BoundaryConditions(; grounding_line = NoSlipGL()) (the default).

source
Laddie.FreeSlipGL — Type
struct FreeSlipGL <: AbstractGroundingLineBC

Free-slip momentum boundary condition at the grounding line: slip factor 0 at walls bordering grounded ice, the free-slip end of the LADDIE v1 convention (no wall drag beyond the zero velocity stored in the wall cell).

Select via BoundaryConditions(; grounding_line = FreeSlipGL()).

source
Laddie.PartialSlipGL — Type
struct PartialSlipGL{FT} <: AbstractGroundingLineBC

Partial-slip momentum boundary condition at the grounding line, with a slip factor between 0 (free slip) and 2 (no slip).

LADDIE v1 applies one factor, slip = 1, to every wall; reproduce it with BoundaryConditions(; grounding_line = PartialSlipGL(1.0), land = PartialSlipLand(1.0)).

Select via BoundaryConditions(; grounding_line = PartialSlipGL(1.0)).

Fields

  • factor::Any: slip factor, from 0 (free slip) to 2 (no slip)
source
Laddie.AbstractLandBC — Type

Abstract supertype for the momentum boundary condition at land walls (mask value 1: exposed bedrock, islands, and the outer border ring). Pass a concrete instance as BoundaryConditions(; land = ...): NoSlipLand (the default), FreeSlipLand or PartialSlipLand.

The grounding line is governed separately by AbstractGroundingLineBC; at a coastline corner whose stencil touches both grounded ice and exposed rock, the grounding-line condition takes precedence (the land wall indicators exclude faces already flagged as grounding line), so each wall face gets exactly one slip factor.

source
Laddie.NoSlipLand — Type
struct NoSlipLand <: AbstractLandBC

No-slip momentum boundary condition at land walls (the default): the tangential velocity vanishes at walls bordering exposed bedrock (mask value 1), which includes islands and ice-free coastline inside the domain as well as the outer border ring. Implemented as a slip factor of 2 on land faces.

Select via BoundaryConditions(; land = NoSlipLand()) (the default).

source
Laddie.FreeSlipLand — Type
struct FreeSlipLand <: AbstractLandBC

Free-slip momentum boundary condition at land walls: slip factor 0 at walls bordering exposed bedrock (see FreeSlipGL).

Select via BoundaryConditions(; land = FreeSlipLand()).

source
Laddie.PartialSlipLand — Type
struct PartialSlipLand{FT} <: AbstractLandBC

Partial-slip momentum boundary condition at land walls, with a slip factor between 0 (free slip) and 2 (no slip). See PartialSlipGL for reproducing LADDIE v1.

Select via BoundaryConditions(; land = PartialSlipLand(1.0)).

Fields

  • factor::Any: slip factor, from 0 (free slip) to 2 (no slip)
