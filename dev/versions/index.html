LADDIE versions

Three codes share the name LADDIE. v1 (Lambert et al. (2023)) runs on a structured Arakawa C-grid. v2 (Lambert et al. (2026)) runs on an unstructured mesh, rewritten and integrated with the UFEMISM ice-sheet model. Laddie.jl implements the v2 physics on the v1 C-grid: it keeps v1's structured grid and stencils, and takes the physical choices that v2 made. Each choice that differs between the two versions is an option of Laddie.jl; the physics and numerics overviews list them, with the default a plain run uses.

Using the versions

Params<Setup>v1 and Params<Setup>v2 return the parameters each published run used, and Simulation<Setup>v1 and Simulation<Setup>v2 build the run itself. The v2 aliases match v2's parameters: they select the v2 options of the physics and numerics overviews, but they run on Laddie.jl's C-grid with leapfrog stepping, so they are not bit-for-bit reproductions. The reproduction page compares both against the published output, and the published setups list every alias.
