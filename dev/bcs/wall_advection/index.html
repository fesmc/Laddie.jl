Wall momentum advection

The wall slip factor always sets the viscous wall stress. Whether it also forms the momentum carried across a wall face by the advection, through a ghost velocity $(1 - \text{slip})\,u$, is selected with BoundaryConditions(; wall_advection = ...):

  • NoWallAdvection, the default: no ghost, the advection sees a factor of 0 at every wall. This is what LADDIE v2 does: both of its advection schemes skip grounded neighbours outright, and its wall is the viscous term alone.
  • SlipScaledWallAdvection: the advection uses the same factor as the viscosity.
  • V1WallAdvection: the advection uses the factor minus one, LADDIE v1's combination (see Wall slip).

Interaction with the advection scheme

This interacts with the momentum-advection scheme, and the interaction is easy to trip over:

  • Under CentredMomentumAdvection the two terms are independent, and wall_advection is a real choice. Switching it off weakens a wall that is otherwise braking the flow twice over.
  • Under UpstreamMomentumAdvection walls carry no momentum by construction, since they carry no mass. wall_advection then has no effect at all — the settings give identical results — and the wall's entire contribution is the viscous one.

The practical consequence is that the pair (scheme, $A_h$) has to be chosen together, not the wall condition on its own. A donor-cell run on a C-grid can need considerably more $A_h$ than v2 uses on its mesh to stay stable, because nothing else resists the flow at the wall: on the small-gap geometry of the ice-shelf gaps example, UpstreamMomentumAdvection at v2's $A_h = 10$ lets the layer run away at the grounding line, and needs $A_h \approx 50$ to hold (measured with the earlier no-slip default, $s = 2$). Treat a large $A_h$ there as the stability crutch it is.

API

Laddie.AbstractWallAdvection — Type

Abstract supertype for how the wall slip condition enters the advective term of the momentum equations, as opposed to the viscous wall drag. Pass a concrete instance as BoundaryConditions(; wall_advection = ...): NoWallAdvection (the default, LADDIE v2), SlipScaledWallAdvection or V1WallAdvection (LADDIE v1).

The slip factor of AbstractSlipAtGL / AbstractSlipAtLand always sets the viscous wall stress; this choice decides which factor, if any, forms the momentum carried across a wall face by the upwind advection.

source
Laddie.NoWallAdvection — Type
struct NoWallAdvection <: AbstractWallAdvection

Carry no momentum across walls: the upwind momentum advection sees a slip factor of 0 at grounding-line and land faces whatever the wall condition is, while the viscous wall stress keeps the factor of AbstractSlipAtGL / AbstractSlipAtLand.

This is the default and what LADDIE v2 does: both of its momentum-advection schemes skip grounded neighbours outright (laddie_velocity.f90, "No flux across grounding line"), and the wall enters only through compute_viscUV. With the default PartialSlipAtGL(1.0) / PartialSlipAtLand(1.0) it reproduces v2's walls.

Select via BoundaryConditions(; wall_advection = NoWallAdvection()) (the default).

source
Laddie.SlipScaledWallAdvection — Type
struct SlipScaledWallAdvection <: AbstractWallAdvection

Apply the wall slip factor to the upwind momentum advection as well as to the viscous wall stress: the tangential momentum flux across a wall face is formed with the same ghost velocity (1 - slip)·u as the viscosity, so free slip (0) leaves the flux at its interior value and no slip (2) reverses it.

Select via BoundaryConditions(; wall_advection = SlipScaledWallAdvection()).

source
Laddie.V1WallAdvection — Type
struct V1WallAdvection <: AbstractWallAdvection

LADDIE v1's wall advection: the upwind momentum advection sees the wall slip factor minus one, as a ghost velocity (2 - slip)·u.

v1 uses one parameter, slip, for both terms, but adds it to a viscous stencil that already holds one unit of wall stress (physics.py:lapU), so its viscous wall is one step stronger than its advective one. v1's published slip = 1 is therefore NoSlipAtGL / NoSlipAtLand in the viscosity, with this advection:

julia> BoundaryConditions(; grounding_line_slip = NoSlipAtGL(), land_slip = NoSlipAtLand(),
                          wall_advection = V1WallAdvection())
BoundaryConditions(open ocean = OutflowOnlyOpenOceanBC, grounding line = NoSlipAtGL, land = NoSlipAtLand, gaps = SinkGapsBC, wall advection = V1WallAdvection)

A v1 slip below 1 maps to PartialSlipAtGL(slip + 1); above 1 it has no counterpart here.

Select via BoundaryConditions(; wall_advection = V1WallAdvection()).
