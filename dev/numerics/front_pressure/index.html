Ice-front pressure gradient

The pressure-gradient force in the momentum equations has three parts: the ice-base slope, the layer-thickness gradient and the density gradient (see the equation reference). The last two difference a cell against its neighbour. At a one-sided face — the ice front, or a SinkGapsBC gap edge — that neighbour is not part of the active domain, and masking pins its stored $H$ and $\delta\rho$ to 0. The thickness-gradient term $g\,\overline{H\delta\rho}\,(H_{x-1}-H)/\Delta x$ is then a full one-sided gradient, as if $H$ collapsed to zero across one grid cell.

LADDIE v1 and v2 disagree on what to do about this, so Params(; front_pressure = ...) makes it a choice:

optionthickness gradientdensity gradientmatches
FullDepthGradient (default)keptkeptLADDIE v1
TruncatedDepthGradientdroppedkeptLADDIE v2
ZeroGradientFrontdroppeddroppedLADDIE v2 description paper
  • FullDepthGradient reproduces LADDIE v1, which Laddie.jl is ported from and validated against. Measured on a warm ISOMIP+ run, the thickness-gradient term is ~150× larger at the ice front than in the interior under it.
  • TruncatedDepthGradient drops the thickness-gradient term, as the LADDIE v2 code does at calving-front faces.
  • ZeroGradientFront also drops the density-gradient term $\tfrac12 g\,\bar H^2\,(\delta\rho_{x-1}-\delta\rho)/\Delta x$. This is the zero lateral gradient at the calving front stated in the LADDIE v2 description paper (Lambert et al. (2026)); the v2 code keeps the density term.

None of them affects the grounding line, where no momentum equation is solved.

API

Laddie.AbstractFrontPressure — Type

Abstract supertype for the treatment of the layer-thickness- and density-gradient parts of the pressure-gradient force at one-sided faces — the ice front, and the edges of a gap demoted to ocean by SinkGapsBC. Pass a concrete instance as Params(; front_pressure = ...): FullDepthGradient (LADDIE v1 v1.x, the default), TruncatedDepthGradient (LADDIE v2) or ZeroGradientFront (the zero-lateral-gradient condition stated by Lambert et al. 2026).

The grounding line is unaffected either way — no momentum equation is solved there.

source
Laddie.FullDepthGradient — Type
struct FullDepthGradient <: AbstractFrontPressure

Keep the layer-thickness-gradient part of the pressure-gradient force at one-sided faces — the ice front, and the edges of a gap demoted to ocean by SinkGapsBC — evaluating it as (H_neighbour - H)/Δ with the neighbour's stored thickness, which masking pins to 0 there. The term is thus a full one-sided gradient, as if H fell to zero across one grid cell.

This is what LADDIE v1 does (integrate.py, -g·ip_t(Ddrho)·(Dxm1 - D)/dx with Dxm1 = roll(D*tmask)), so it is the default and the setting under which Laddie.jl reproduces the LADDIE v1 code.

Select via Params(; front_pressure = FullDepthGradient()) (the default).

See also TruncatedDepthGradient.

source
Laddie.TruncatedDepthGradient — Type
struct TruncatedDepthGradient <: AbstractFrontPressure

Drop the layer-thickness-gradient part of the pressure-gradient force at one-sided faces — the ice front, and the edges of a gap demoted to ocean by SinkGapsBC — keeping only the ice-base-slope and density-gradient parts there.

This is what the LADDIE v2 does at calving-front faces (laddie_velocity.f90:118-126, IF (mask_cf_b .OR. mask_gl_b) ... assume dH/dx = 0). It avoids treating a masked neighbour's stored H = 0 as a real thickness: under FullDepthGradient that term is roughly 150× larger at the ice front than in the interior on a warm ISOMIP+ run.

Neither choice affects the grounding line, where the velocity masks are zero and no momentum equation is solved at all.

Select via Params(; front_pressure = TruncatedDepthGradient()).

See also ZeroGradientFront, which drops the density-gradient part as well.

source
Laddie.ZeroGradientFront — Type
struct ZeroGradientFront <: AbstractFrontPressure

Drop both the layer-thickness-gradient and the density-gradient parts of the pressure-gradient force at one-sided faces — the ice front, and the edges of a gap demoted to ocean by SinkGapsBC — keeping only the ice-base-slope part there.

Under TruncatedDepthGradient the density-gradient term is still evaluated as (δρ_neighbour - δρ)/Δ, with the neighbour's stored δρ, which masking pins to 0: a one-sided gradient, as if the layer were neutrally buoyant across one grid cell. This option makes the momentum equation consistent with the condition stated in the LADDIE v2 description paper (Lambert et al. 2026), "zero lateral gradients are applied to all main variables (H, U, V, T, and S)" at the calving front. The v2 code comments the same intent (laddie_velocity.f90:119, "Assume dH/dx and ddrho/dx = 0") but keeps the ddrho_amb_dx_b term in its code.

Select via Params(; front_pressure = ZeroGradientFront()).
